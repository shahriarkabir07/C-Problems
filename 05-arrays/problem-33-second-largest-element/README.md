# Problem 33: Second Largest Element in an Array

## Problem Statement
Read N integers and find the second largest distinct value in the array.

## Input
First N, then N integers.

## Output
The second largest value in the array.

## Example Input
```
5
10 20 4 45 99
```

## Example Output
```
45
```

## Explanation
Track the largest and second largest values in a single pass, updating both as needed while scanning the array.
