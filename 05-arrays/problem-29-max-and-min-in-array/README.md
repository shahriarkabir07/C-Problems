# Problem 29: Maximum and Minimum in an Array

## Problem Statement
Read N integers and find the maximum and minimum values.

## Input
First an integer N, then N integers.

## Output
The maximum value, then the minimum value.

## Example Input
```
5
4 8 1 9 3
```

## Example Output
```
9 1
```

## Explanation
Initialize max and min with the first element, then loop through and update them when a larger or smaller value is found.
