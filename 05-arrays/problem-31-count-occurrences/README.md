# Problem 31: Count Occurrences of an Element

## Problem Statement
Read N integers and a target value, then count how many times the target appears in the array.

## Input
First N, then N integers, then the target value.

## Output
The count of occurrences of the target.

## Example Input
```
6
1 2 2 3 2 4
2
```

## Example Output
```
3
```

## Explanation
Loop through the array and increment a counter whenever the current element equals the target.
