# Problem 27: Array Input and Output

## Problem Statement
Read N integers into an array and print them back.

## Input
First an integer N, then N integers.

## Output
The N integers separated by space.

## Example Input
```
4
10 20 30 40
```

## Example Output
```
10 20 30 40
```

## Explanation
Read N first, then use a loop to read N values into an array, and another loop to print them.
