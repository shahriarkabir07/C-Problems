# Problem 30: Linear Search

## Problem Statement
Read N integers and a target value, then find the index of the target in the array (0-based). Print -1 if not found.

## Input
First N, then N integers, then the target value.

## Output
The index of the target, or -1 if not found.

## Example Input
```
5
10 20 30 40 50
30
```

## Example Output
```
2
```

## Explanation
Loop through the array comparing each element to the target; return the index when found.
