# Problem 32: Reverse an Array

## Problem Statement
Read N integers and print the array reversed.

## Input
First N, then N integers.

## Output
The array elements in reverse order.

## Example Input
```
5
1 2 3 4 5
```

## Example Output
```
5 4 3 2 1
```

## Explanation
Print the array elements starting from the last index down to the first.
