# Problem 28: Sum and Average of an Array

## Problem Statement
Read N integers and calculate their sum and average.

## Input
First an integer N, then N integers.

## Output
The sum, then the average.

## Example Input
```
5
1 2 3 4 5
```

## Example Output
```
15 3
```

## Explanation
Add up all elements in a loop, then divide the sum by N to get the average.
