# Problem 41: Function to Calculate Factorial

## Problem Statement
Write a function factorial(int n) that returns the factorial of n, then use it in main().

## Input
A single non-negative integer.

## Output
The factorial of the number.

## Example Input
```
6
```

## Example Output
```
720
```

## Explanation
Define a function that multiplies numbers from 1 to n using a loop and returns the result.
