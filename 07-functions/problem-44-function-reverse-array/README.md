# Problem 44: Function to Reverse an Array

## Problem Statement
Write a function reverseArray(int arr[], int n) that reverses an array in place, then print the result in main().

## Input
First N, then N integers.

## Output
The reversed array elements separated by space.

## Example Input
```
5
1 2 3 4 5
```

## Example Output
```
5 4 3 2 1
```

## Explanation
Define a function that swaps elements from both ends of the array moving toward the middle, modifying the array in place.
