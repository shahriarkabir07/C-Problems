# Problem 42: Function to Find GCD

## Problem Statement
Write a function gcd(int a, int b) using the Euclidean algorithm, then use it in main() to find the GCD of two numbers.

## Input
Two integers separated by space.

## Output
The GCD of the two numbers.

## Example Input
```
24 36
```

## Example Output
```
12
```

## Explanation
Define a recursive or iterative function implementing the Euclidean algorithm, then call it with the two input values.
