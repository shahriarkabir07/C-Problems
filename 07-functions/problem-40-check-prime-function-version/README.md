# Problem 40: Check Prime (Function Version)

## Problem Statement
Write a function isPrime(int n) that returns true if n is prime, then use it in main() to check a number read from input.

## Input
A single integer.

## Output
"Prime" or "Not Prime".

## Example Input
```
23
```

## Example Output
```
Prime
```

## Explanation
Define a boolean function that checks divisibility up to the square root of n, then call it from main() and print based on its return value.
