# Problem 43: Function Returning Maximum of Three Numbers

## Problem Statement
Write a function maxOfThree(int a, int b, int c) that returns the largest of three numbers.

## Input
Three integers separated by space.

## Output
The largest of the three numbers.

## Example Input
```
3 9 6
```

## Example Output
```
9
```

## Explanation
Define a function that uses conditional comparisons to determine and return the maximum value.
