# Problem 26: LCM of Two Numbers

## Problem Statement
Read two integers and find their Least Common Multiple (LCM).

## Input
Two integers separated by space.

## Output
The LCM of the two numbers.

## Example Input
```
4 6
```

## Example Output
```
12
```

## Explanation
Calculate the GCD first, then use the formula LCM = (a * b) / GCD.
