# Problem 22: Prime Number Checker

## Problem Statement
Read an integer and determine whether it is a prime number.

## Input
A single integer greater than 1.

## Output
"Prime" or "Not Prime".

## Example Input
```
17
```

## Example Output
```
Prime
```

## Explanation
Check divisibility from 2 up to the square root of the number; if none divide it evenly, it is prime.
