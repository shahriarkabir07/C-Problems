# Problem 24: Find Factors of a Number

## Problem Statement
Read an integer and print all of its positive factors.

## Input
A single positive integer.

## Output
All factors of the number, separated by space.

## Example Input
```
12
```

## Example Output
```
1 2 3 4 6 12
```

## Explanation
Loop from 1 to the number and check which values divide it evenly.
