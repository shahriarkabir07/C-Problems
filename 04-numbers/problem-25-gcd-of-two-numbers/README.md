# Problem 25: GCD of Two Numbers

## Problem Statement
Read two integers and find their Greatest Common Divisor (GCD).

## Input
Two integers separated by space.

## Output
The GCD of the two numbers.

## Example Input
```
12 18
```

## Example Output
```
6
```

## Explanation
Use the Euclidean algorithm: repeatedly replace the larger number with the remainder of dividing it by the smaller number.
