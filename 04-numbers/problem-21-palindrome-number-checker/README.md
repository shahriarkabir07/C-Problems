# Problem 21: Palindrome Number Checker

## Problem Statement
Read an integer and check whether it is a palindrome (reads the same forward and backward).

## Input
A single integer.

## Output
"Palindrome" or "Not Palindrome".

## Example Input
```
12321
```

## Example Output
```
Palindrome
```

## Explanation
Reverse the number and compare it with the original number.
