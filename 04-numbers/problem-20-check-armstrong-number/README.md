# Problem 20: Check Armstrong Number

## Problem Statement
Read a 3-digit integer and check if it is an Armstrong number (sum of cubes of its digits equals the number itself).

## Input
A single 3-digit integer.

## Output
"Armstrong" or "Not Armstrong".

## Example Input
```
153
```

## Example Output
```
Armstrong
```

## Explanation
Extract each digit, cube it, sum the cubes, and compare the sum to the original number.
