# Problem 23: Print All Prime Numbers up to N

## Problem Statement
Read an integer N and print all prime numbers from 2 up to N.

## Input
A single integer N.

## Output
All prime numbers up to N, separated by space.

## Example Input
```
20
```

## Example Output
```
2 3 5 7 11 13 17 19
```

## Explanation
For each number from 2 to N, check if it is prime using divisibility tests, and print it if it is.
