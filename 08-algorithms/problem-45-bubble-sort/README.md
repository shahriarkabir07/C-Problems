# Problem 45: Bubble Sort Implementation

## Problem Statement
Read N integers and sort them in ascending order using the Bubble Sort algorithm.

## Input
First N, then N integers.

## Output
The sorted array elements separated by space.

## Example Input
```
5
5 2 9 1 5
```

## Example Output
```
1 2 5 5 9
```

## Explanation
Repeatedly compare adjacent elements and swap them if they are in the wrong order, passing through the array multiple times.
