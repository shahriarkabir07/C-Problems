# Problem 47: Selection Sort Implementation

## Problem Statement
Read N integers and sort them in ascending order using the Selection Sort algorithm.

## Input
First N, then N integers.

## Output
The sorted array elements separated by space.

## Example Input
```
5
29 10 14 37 13
```

## Example Output
```
10 13 14 29 37
```

## Explanation
For each position, find the minimum element in the remaining unsorted part of the array and swap it into place.
