# Problem 03: Swap Two Numbers

## Problem Statement
Read two integers and swap their values without using a third variable, then print them.

## Input
Two integers separated by space.

## Output
The two integers after swapping, separated by space.

## Example Input
```
3 8
```

## Example Output
```
8 3
```

## Explanation
Use arithmetic operations (addition and subtraction) to swap the values of the two variables without needing an extra variable.
