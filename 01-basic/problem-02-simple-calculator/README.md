# Problem 02: Simple Calculator

## Problem Statement
Read two numbers and an operator (`+`, `-`, `*`, `/`). Print the result of applying the operator to the two numbers.

## Input
Two numbers and an operator character, separated by space.

## Output
The result of the operation.

## Example Input
```
10 5 *
```

## Example Output
```
50
```

## Explanation
Read the two numbers and the operator character, then use an if-else chain to decide which arithmetic operation to perform.
