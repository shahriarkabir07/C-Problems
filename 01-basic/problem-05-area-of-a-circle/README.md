# Problem 05: Area of a Circle

## Problem Statement
Read the radius of a circle and calculate its area.

## Input
A single number representing the radius.

## Output
The area of the circle, using pi = 3.14159.

## Example Input
```
5
```

## Example Output
```
78.5397
```

## Explanation
Use the formula `Area = pi * radius * radius` with pi defined as a constant.
