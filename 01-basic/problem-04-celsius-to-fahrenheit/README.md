# Problem 04: Celsius to Fahrenheit

## Problem Statement
Read a temperature in Celsius and convert it to Fahrenheit.

## Input
A single number representing degrees Celsius.

## Output
The equivalent temperature in Fahrenheit.

## Example Input
```
100
```

## Example Output
```
212
```

## Explanation
Use the formula `F = (C * 9 / 5) + 32` to convert Celsius to Fahrenheit.
