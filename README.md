# 50 Small C++ Programming Problems

This repository contains 50 small C++ problems designed to build strong programming fundamentals and problem-solving skills. The problems progress gradually from beginner to intermediate level, covering core computer science topics used in coding interviews and contests.

* 🏫 Daffodil International University
* 💻 Language: C++
* 📚 Problems: 50
* 🎯 Purpose: Programming practice and problem-solving

## Topics Covered

* Basic Programming (I/O, variables, arithmetic)
* Conditional Statements
* Loops and Patterns
* Number Theory Problems
* Arrays
* Strings
* Functions
* Basic Algorithms (Searching, Sorting)
