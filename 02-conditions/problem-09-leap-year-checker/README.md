# Problem 09: Leap Year Checker

## Problem Statement
Read a year and determine whether it is a leap year.

## Input
A single integer representing a year.

## Output
"Leap Year" or "Not a Leap Year".

## Example Input
```
2024
```

## Example Output
```
Leap Year
```

## Explanation
A year is a leap year if it is divisible by 4 and (not divisible by 100 or divisible by 400).
