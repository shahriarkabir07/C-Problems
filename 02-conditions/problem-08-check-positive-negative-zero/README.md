# Problem 08: Check Positive, Negative, or Zero

## Problem Statement
Read a number and determine whether it is positive, negative, or zero.

## Input
A single integer.

## Output
"Positive", "Negative", or "Zero".

## Example Input
```
-5
```

## Example Output
```
Negative
```

## Explanation
Use if-else if-else to check the sign of the number.
