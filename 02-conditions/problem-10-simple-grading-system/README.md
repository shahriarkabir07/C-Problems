# Problem 10: Simple Grading System

## Problem Statement
Read a student's marks (0-100) and print their grade based on the scale: 90+ = A, 80-89 = B, 70-79 = C, 60-69 = D, below 60 = F.

## Input
A single integer between 0 and 100.

## Output
A single character representing the grade.

## Example Input
```
85
```

## Example Output
```
B
```

## Explanation
Use a chain of if-else if statements to check which range the marks fall into.
