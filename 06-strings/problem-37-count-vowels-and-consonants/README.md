# Problem 37: Count Vowels and Consonants

## Problem Statement
Read a string and count the number of vowels and consonants in it (letters only).

## Input
A single word (no spaces, letters only).

## Output
The count of vowels, then the count of consonants.

## Example Input
```
hello
```

## Example Output
```
2 3
```

## Explanation
Loop through each character, check if it is a vowel (a, e, i, o, u), and update the vowel or consonant counter accordingly.
