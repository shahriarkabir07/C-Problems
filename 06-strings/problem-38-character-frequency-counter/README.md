# Problem 38: Character Frequency Counter

## Problem Statement
Read a string and a character, then count how many times that character appears in the string.

## Input
A string, then a single character.

## Output
The number of occurrences of the character.

## Example Input
```
programming
g
```

## Example Output
```
2
```

## Explanation
Loop through the string and increment a counter whenever the current character matches the target character.
