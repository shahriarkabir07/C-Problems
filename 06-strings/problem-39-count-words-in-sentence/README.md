# Problem 39: Count Words in a Sentence

## Problem Statement
Read a full line of text and count how many words it contains.

## Input
A single line of text.

## Output
The number of words.

## Example Input
```
I love programming in C++
```

## Example Output
```
5
```

## Explanation
Use a stringstream to split the line by whitespace and count how many tokens are extracted.
