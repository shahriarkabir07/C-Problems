# Problem 34: String Length Without strlen()

## Problem Statement
Read a string and calculate its length without using the built-in strlen() or .length() function.

## Input
A single word (no spaces).

## Output
The length of the string.

## Example Input
```
hello
```

## Example Output
```
5
```

## Explanation
Loop through the string character by character using an index until the null terminator or end of string object is reached, counting each character.
