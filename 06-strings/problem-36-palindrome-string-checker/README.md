# Problem 36: Palindrome String Checker

## Problem Statement
Read a string and check if it is a palindrome (reads the same forward and backward).

## Input
A single word (no spaces).

## Output
"Palindrome" or "Not Palindrome".

## Example Input
```
madam
```

## Example Output
```
Palindrome
```

## Explanation
Compare characters from the start and end of the string moving toward the middle; if all pairs match, it is a palindrome.
