# Problem 11: Print Numbers 1 to N

## Problem Statement
Read an integer N and print all numbers from 1 to N, each on the same line separated by space.

## Input
A single integer N.

## Output
Numbers from 1 to N separated by space.

## Example Input
```
5
```

## Example Output
```
1 2 3 4 5
```

## Explanation
Use a for loop starting at 1 and incrementing up to N, printing each value.
