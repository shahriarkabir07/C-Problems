# Problem 12: Sum of Natural Numbers

## Problem Statement
Read an integer N and print the sum of all natural numbers from 1 to N.

## Input
A single integer N.

## Output
The sum of numbers from 1 to N.

## Example Input
```
5
```

## Example Output
```
15
```

## Explanation
Loop from 1 to N, adding each number to a running total.
