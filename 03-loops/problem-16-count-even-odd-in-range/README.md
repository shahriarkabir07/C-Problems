# Problem 16: Count Even and Odd in a Range

## Problem Statement
Read two integers L and R, then count how many even and odd numbers exist between L and R (inclusive).

## Input
Two integers L and R.

## Output
Two integers: count of even numbers, then count of odd numbers.

## Example Input
```
1 10
```

## Example Output
```
5 5
```

## Explanation
Loop from L to R, using the modulus operator to classify each number as even or odd and updating counters.
