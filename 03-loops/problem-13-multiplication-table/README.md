# Problem 13: Multiplication Table

## Problem Statement
Read an integer N and print its multiplication table from 1 to 10.

## Input
A single integer N.

## Output
10 lines, each showing N x i = result.

## Example Input
```
3
```

## Example Output
```
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```

## Explanation
Loop i from 1 to 10 and print N multiplied by i in the required format.
